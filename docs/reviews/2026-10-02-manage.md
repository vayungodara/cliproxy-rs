# Config and Management API review (ultra/manage, 2026-10-02)

Review of the config/management subset merged at `794b2b8` against CLIProxyAPI
`6fecc6e`. Go code is the reference; expected values in the tests come from the real
Go handlers (`crates/cpa-server/tests/reference/manage`). Status is per increment.

## Access rules (fixed in increment 1)

1. Local/remote: Rust treated any loopback address (`127.0.0.0/8`, mapped forms) as
   local and never consulted `trusted-proxies`. Go compares the gin client IP text
   with exactly `127.0.0.1` or `::1`, after trusted-proxy resolution of
   `X-Forwarded-For` then `X-Real-IP`.
2. `server.trusted-proxies` was neither parsed nor validated. Go rejects empty,
   padded and unparsable entries at load with specific messages, and applies the
   list at startup only.
3. Bans: Go checks an active ban first, bans on the fifth counted failure (missing
   or wrong key), keeps counts until success, ban or a 2 h idle purge, and reports
   `IP banned due to too many failed attempts. Try again in 30m0s`. Rust banned on a
   rolling window, reset counts after 30 minutes, and omitted the remaining time.
4. Availability: with no secret Go serves a bare 404 from its availability gate;
   `MANAGEMENT_PASSWORD` keeps routes on; a `--password` alone enables routes until
   the first reload, and the middleware then still answers 403
   `remote management key not set`. Rust answered `{"error":"not_found"}` from the
   auth middleware and had no `--password`.
5. Headers: `X-CPA-SUPPORT-PLUGIN` was `false` (Go: `0`/`1`), `X-CPA-COMMIT` and
   `X-CPA-BUILD-DATE` were missing, `Cache-Control: no-store` was sent everywhere
   (Go: config reads only), and JSON lacked gin's `; charset=utf-8`.
6. Routing: unknown paths returned an authenticated 501, wrong methods 405 with an
   `Allow` header, and HEAD was served by GET. Go answers all three with a bare 404
   before authentication.
7. CORS: Go's global middleware adds four CORS headers to every response and ends
   every OPTIONS request with 204 before routing. Rust had none, so a cross-origin
   dashboard could not connect.
8. Non-UTF-8 key bytes were dropped instead of compared as bytes.

Not reproduced: gin's trailing-slash redirect (`DELETE /v8/management/config`
returns 307 to `/config/` in Go; 404 here).

## Credentials (fixed in increment 1)

9. Config API keys (`gemini`, `interactions`, `claude`, `codex`, `xai`, `meta`,
   `openai-compatibility`, `vertex`) never became runtime credentials. They are now
   synthesized with Go's IDs, labels, attributes, metadata and sanitizers, and
   republished on every management write and watcher reload.
10. Auth-dir loading missed Go rules: case-insensitive `.json`, trimmed lowercase
    `type`, `gemini` skipped as `gemini-cli`, metadata key aliases normalized,
    invalid weights rejected, and the attributes the scheduler reads (file
    priority, weight, note, headers, prefix, excluded models merged with
    `oauth.excluded-models`, Codex plan type).
11. The interim listing showed config API keys as `runtime_only` and used the
    credential ID as `auth_index`; Go lists file/runtime-only auths only and derives
    a sha256 index.
12. `oauth.request-scoped-errors` never reached the scheduler policy.

## Oracle review of increment 1 (fixed unless noted)

- High: forwarded headers were decoded with `to_str()`, so a non-ASCII entry left of
  a valid client address made the whole header unusable and a trusted loopback peer
  became the client: remote requests were treated as local. Parsing is now
  byte-wise, right to left, exactly like gin. Go fixtures added.
- High: an unreadable `auth-dir` aborted publication, leaving a rotated or removed
  management secret active. Go treats a failed `ReadDir` as an empty file set; the
  config, availability and API-key credentials now always publish. The watcher no
  longer stalls on an unreadable auth dir.
- Medium: file credentials carry Go's normalized prefix, exclusions and aliases in
  attributes, but `scheduler.rs` reads raw metadata. The prefix attribute is now
  always present for files, so a rejected raw prefix can no longer be used.
  Open (scheduler owner): read `attributes.excluded_models` (comma-joined, includes
  `oauth.excluded-models`) and `attributes.model_aliases` (sanitized JSON) before
  metadata.
- Low: zoned IPv6 peers now yield Go's empty client IP; `MANAGEMENT_PASSWORD` is
  read and trimmed as bytes.
- Decision kept: Go's default trusts no proxy, so a loopback tunnel makes every
  client local. Behaviour stays Go's; a one-time warning names the fix
  (`server.trusted-proxies: [127.0.0.1, "::1"]` and a restart).

## Config (open)

13. GET returns unknown root sections; Go's read-time migration comments them out.
14. Load does not remove conflicting legacy keys from the file, as Go's loader does.
15. Writes skip Go's saver: sanitized values, list-item field pruning and
    materialized non-default keys.
16. Go defaults and validation are missing from the typed view (credential
    concurrency, in-flight, live-media relay, discovery, retention clamps).
17. JSON writes touching TURN servers return 501 instead of preserving redacted
    secrets by endpoint.
18. Watcher: 50 ms content polling instead of fsnotify-equivalent events, and a
    missing config file errors every tick.

## Routes (open)

Missing v8 routes: OAuth start/status/callback/cancel/import, credential upload,
delete, fields, models and refresh, cooldown reset, model definitions, latest
version, API call, logs, usage, plugins.
