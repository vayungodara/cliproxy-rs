# Performance budgets, checked by bench/gate.sh (size, idle) and by
# crates/cpa-server/tests/alloc_budget.rs (heap per request) on GitHub-hosted runners.
#
#   <key> <value> <tolerance %>
#
# A measurement fails when it exceeds value * (1 + tolerance / 100). Byte budgets are the
# last accepted measurement with 2% of room; counts that must stay near zero have none.
# A change that needs more raises the value here, with a dated line above it that names
# the feature and its cost, as ui/scripts/size.mjs does for the dashboard:
#
#   # 2026-11-02: Homebrew service hook, +18 KB .text.
#
# A key without a line is reported and not gated, so a new target or metric starts by
# reporting. Targets from docs/BENCHMARKS.md that these do not meet yet are noted next to
# their lines; the budgets hold today's numbers so that nothing gets worse meanwhile.
